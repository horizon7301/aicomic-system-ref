# 《开局挂科？我的绩点系统满级了》 AI漫剧 (AI comic drama) project

A 系统流 (system power-up) campus comic made with AI image generation, loosely based on my own life as an EE student and basketball referee.

**Status:** Paused (Oct 2026). See [POSTMORTEM.md](POSTMORTEM.md) for the review, and [复盘-中文.md](复盘-中文.md) for the Chinese version.

- `series-bible.md`: world, characters and rules
- `ep01-storyboard.md`: the 17-panel storyboard for Episode 1
- `assets/`: character sheets and backgrounds
- `ep01/`: generated panels P1–P11, including rejected versions
